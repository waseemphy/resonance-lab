# Resonance Lab

An interactive resonance simulation for A Level Physics students.

Students can explore:

- natural frequency and driving frequency
- resonance and frequency ratio
- the amplitude response curve
- phase lag between driving force and displacement
- the effect of damping on the resonance peak
